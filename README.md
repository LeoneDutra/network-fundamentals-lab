# Network Fundamentals Lab

Hands-on exercises to strengthen understanding of core networking concepts used in cybersecurity and cloud environments.

## 🌐 Topics
- TCP/IP fundamentals
- DNS, DHCP, ARP
- Routing and switching basics
- Firewall rules and network segmentation
- Packet capture and protocol analysis with Wireshark

## 📂 Repository Structure
- topologies/
- configs/
- pcaps/
- protocol-notes/
- lab-guides/

## 🎯 Objectives
- Master the foundations of networking  
- Support cloud and security study paths  
- Build reference material for troubleshooting and analysis
